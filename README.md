# 🚀 PlacementPilot AI

PlacementPilot AI is a full-stack AI-powered placement management platform designed for students.

## ✨ Features

- 🔐 Authentication
- 🏢 Company Explorer
- 📋 Application Tracker
- 📄 AI Resume Analyzer
- 🤖 AI Interview Preparation
- 📊 Placement Analytics
- 👤 Student Profile
- 🔔 Notifications
- 📈 Dashboard

## 🛠️ Tech Stack

### Frontend
- React
- Vite
- Tailwind CSS
- React Router
- Framer Motion
- Recharts

### Backend
- Node.js
- Express.js
- MongoDB
- Mongoose
- JWT
- bcrypt

### AI
- Gemini API
